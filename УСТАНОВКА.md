# ЕИГ — установка на Android

## Про APK: честно

Настоящий подписанный `.apk` я собрать не смог — для этого нужен Android SDK, который качается с `dl.google.com`, а этот домен закрыт в моей рабочей среде. Поэтому здесь лежит **PWA**: приложение, которое Android ставит на домашний экран со своим значком, запускает в полноэкранном режиме без адресной строки и работает офлайн. Функционально от APK ты не отличишь.

Если нужен именно файл `.apk` (например, чтобы поставить без интернета или раздать) — путь описан в разделе 3, занимает минут пять.

---

## 1. Быстрый вариант — просто открыть

Скинь `index.html` на телефон и открой в браузере. Работает всё, кроме офлайн-режима и установки на экран (Chrome не даёт service worker с `file://`).

Годится, чтобы попробовать. Для постоянного использования — вариант 2.

---

## 2. Установка как приложение (рекомендую)

Нужен HTTPS-хостинг. Бесплатно и за пару минут — GitHub Pages.

**Шаги:**

1. Создай репозиторий на GitHub (можно приватный — Pages работает и с ним на платных планах; на бесплатном нужен публичный).
2. Загрузи туда содержимое папки `eig-app` — все файлы в корень:
   ```
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   icon-512-maskable.png
   apple-touch-icon.png
   ```
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`. Сохрани.
4. Через минуту адрес вида `https://<твой-логин>.github.io/<репозиторий>/` заработает.
5. Открой этот адрес в **Chrome на телефоне** → меню (⋮) → **«Установить приложение»** / «Добавить на главный экран».

Готово: значок на рабочем столе, запуск без браузерной обвязки, работа без сети.

**Альтернативы хостингу**, если не хочешь GitHub: Netlify Drop (перетащил папку — получил ссылку), Vercel, Cloudflare Pages. Или свой сервер — ты это умеешь, важно только чтобы был HTTPS.

---

## 3. Если нужен настоящий APK

Когда PWA уже лежит по адресу из шага 2:

1. Открой **https://www.pwabuilder.com**
2. Вставь адрес своего PWA, нажми Start.
3. Вкладка **Android** → **Generate Package**.
4. Получишь `.zip`, внутри — подписанный `app-release-signed.apk` плюс ключ подписи (`signing.keystore` и пароли в `assetlinks.json`/README пакета). **Сохрани ключ**: без него не выпустишь обновление.
5. Перекинь APK на телефон, разреши установку из неизвестных источников, установи.

PWABuilder оборачивает сайт в TWA (Trusted Web Activity) — это тот же движок Chrome, но полноценное Android-приложение с своим процессом и значком.

Альтернатива для локальной сборки, если захочешь собрать сам и SDK у тебя есть: `npx @bubblewrap/cli init --manifest https://.../manifest.webmanifest`, затем `bubblewrap build`.

## Данные

Всё хранится в `localStorage` на устройстве. Наружу ничего не уходит, аккаунтов нет.

**Важно:** переустановка приложения, очистка данных Chrome или смена домена стирают историю. На вкладке **Лог** есть кнопки **Экспорт JSON** и **Экспорт CSV** — выгружай раз в пару недель. CSV открывается в Excel (разделитель `;`, кодировка UTF-8 с BOM, кириллица не поедет).

Ключи хранилища, если захочешь дёргать их скриптом:
- `eig_checkins_v1` — ежедневные чек-ины (индекс, z, режим, ответы опросника)
- `eig_sessions_v1` — записанные тренировки (упражнения, вес, повторы, кардио)
- `eig_draft_v1` — незавершённая сегодняшняя тренировка

---

## Что внутри

**Вкладка «Сегодня»** — опросник из 6 пунктов + часы сна → индекс 0–100 → режим относительно твоего базелайна → сессия с чекбоксами. Каждое упражнение отмечается галочкой, рядом поля для веса и фактических повторов. Прогресс-бар сверху. Кнопка «Завершить тренировку» пишет всё в лог. Незавершённая сессия сохраняется автоматически — можно закрыть приложение посреди тренировки и вернуться.

**Вкладка «Календарь»** — месячная сетка. Цвет точки = режим дня, галочка = тренировка записана. Тап по дню открывает детали: индекс, ответы опросника, что было сделано и с каким весом. Ниже график индекса за 30 дней с цветными зонами.

**Вкладка «Лог»** — сводка за 28 дней (тренировок, средний индекс, минуты Zone 2 против цели, суммарные рабочие подходы) и список всех сессий с раскрывающимися деталями.

## Калибровка

Первые ~7 дней режим считается по абсолютным порогам — базелайна ещё нет. Дальше система переходит на z-score относительно твоего личного среднего за 7 дней, и в интерфейсе появляется строка «база NN · z ±N.NN».

APRE настроен на целевой коридор 12 повторов. Если твои рабочие диапазоны в жимах и тягах разойдутся — скажи, вынесу целевое число в настройку по каждому упражнению.
